Ouvrir la page d'installation

Dans votre navigateur, accédez à la page d'installation du Super Admin :

/setup

Cette page est spécialement conçue pour l'initialisation initiale du système.

⚠️ Important : Cette page nécessite que le serveur de développement soit en cours d'exécution (bun run dev)

Identifier le statut actuel

La page affiche automatiquement le statut du Super Admin :

  • 🟡 Super Admin non initialisé → Le bouton d'initialisation est visible
  • 🟢 Super Admin configuré → Le compte existe déjà

Cliquer sur "Initialiser le Super Admin"

Si le Super Admin n'existe pas encore, vous verrez un bouton orange :

👤 Initialiser le Super Admin

Cliquez sur ce bouton pour créer le compte.

Attendre la confirmation

Pendant la création, un spinner d'chargement s'affiche :

⏳ Création en cours...

Une fois terminé, un message de succès apparaît avec les informations du compte créé.

Aller à la page de connexion

Après la création réussie, cliquez sur le bouton :

→ Aller à la page de connexion

Vous serez redirigé vers la page /connexion
